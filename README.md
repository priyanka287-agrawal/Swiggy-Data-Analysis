# Swiggy Data Analysis Dashboard 🛵📊

An end-to-end Power BI project analyzing Swiggy's food delivery ecosystem, focusing on sales performance, user demographics, and regional growth metrics.

## 🚀 Overview
This project transforms raw delivery data into a multi-page interactive dashboard. By utilizing Python for data cleaning and Power BI for visualization, the analysis identifies key revenue drivers and customer behavioral patterns across various Indian cities.

## 🛠️ Project Structure
* **Data Cleaning:** Python (Pandas) via `Swigy.ipynb`
* **Visualization:** Power BI Desktop
* **Key Visuals:** DAX Measures, Custom Navigation, Map Visuals, and Pareto Analysis

### 2. User Performance & Demographics
